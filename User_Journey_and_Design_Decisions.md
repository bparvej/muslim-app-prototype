# Ummah Connect - UI/UX Prototype

This prototype includes the 11 requested screens integrated into a highly realistic, interactive mobile web wrapper. It reflects the design language, color palette, and user flows outlined in the product vision.

## Design Decisions

1. **Color Palette Application**: 
   - **Primary Emerald (#075B45)** is used for active states, primary buttons, and hero elements (like the Splash screen and Next Prayer card) to instill trust and a connection to Islamic heritage.
   - **Secondary Gold (#D6B66D)** is used sparingly for accents (icons, highlights) to provide a premium feel without being ostentatious.
   - **Background Ivory (#F7F5EE)** is used globally instead of stark white. This reduces eye strain, feels more natural/welcoming, and gives the app a modern editorial look.
   
2. **Typography**: 
   - **Inter** is used for English UI elements to ensure clean, modern readability at small sizes.
   - **Noto Sans Bengali** ensures beautiful, accurate rendering of Bangla text.

3. **User Journey & Layout Strategy (Usability First)**:
   - **Bottom Navigation**: Always present for core loops. `Home`, `Discover`, `Bazaar`, `Daily`, and `Profile`.
   - **Home Screen Density**: Prioritizes immediately actionable info—current time, next prayer countdown, and a quick row for all 5 prayers. 
   - **Visual Hierarchy**: White space and subtle drop shadows (14-18px border radius) group related content (Mosque details, Hadith of the day) securely together.
   
4. **Localization to Dhaka Context**:
   - Sample data reflects the target audience (Baitul Mukarram, Star Kabab, Islamic Foundation calculation methods, Dhaka distances).

## How to View
1. Extract the ZIP file.
2. Open `index.html` in any modern web browser.
3. Use the bottom navigation and clickable cards to interact with the prototype.
